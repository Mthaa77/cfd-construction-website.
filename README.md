# CFD Construction & Handyman Services — Website Concept

This repository contains the v17 single-page website concept prepared by Carter Digitals for CFD Construction & Handyman Services.

## Preview

Live concept demo: https://cfdconstructionclientdemo.vercel.app/

## Important

This is a concept/demo website, not an approved official CFD Construction website. Keep the `noindex, nofollow` setting in place until CFD approves the website for public launch.

## Deployment

The website is a standalone HTML page. The main file is `index.html`. It can be deployed as a static site on Vercel or another static hosting provider with no build command required.
